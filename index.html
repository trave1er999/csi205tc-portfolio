01 — About

Curious about what happens below the browser tab

What I work on

My coursework spans transport-layer behaviour, distributed data processing and applied machine learning. I enjoy measuring things: packet captures, throughput numbers, shuffle sizes and model metrics are all part of the same habit of asking "why is it slow?".

How I build

Small, readable modules with explicit interfaces. I write tests for the tricky parts, keep configuration in CLI flags, and document the protocol in the code so that the next reader does not need to guess the wire format.

Currently learning

Spark internals (DAG scheduling, shuffle spills), QUIC and HTTP/3, and the practical side of network security: TLS handshakes, certificate chains and congestion control behaviour on lossy links.
